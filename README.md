## 🚀 Quickstart Guides

### Week 2 — Prototype Web Pages
Simply double-click or open any HTML file directly in Google Chrome, Safari, or Edge:
- Open [`week2_prototype_pages/login.html`](./week2_prototype_pages/login.html) to begin the interactive flow.

### Week 4 — Evolutionary Prototype Application
```bash
# Navigate to the Week 4 directory
cd week4_evolutionary_prototype

# Start the development server
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to experience the full operational system.
