# Week 2 — Rapid Throwaway Prototype Web Pages

## 🌐 Prototype Web Pages (Website)
This folder contains the **3 throwaway prototype web pages** developed to elicit and validate stakeholder requirements for the Stock Maintenance System:

1. **[`login.html`](./login.html)**:
   - Centered glassmorphic card with dark radial dot background.
   - Gold gradient interactive button with simulated authentication.
   - Pre-filled prototype credentials (`admin` / `••••••••`).
   - Throwaway prototype warning banner.

2. **[`dashboard.html`](./dashboard.html)**:
   - Sticky executive navigation sidebar with profile status.
   - 4 real-time KPI telemetry cards (Total Items, Low Stock Alerts, Inventory Valuation, Pending Orders).
   - 8-row recent stock movements table with IN, OUT, and ADJUSTED status chips.
   - Critical reorder radar with visual progress bars.
   - Floating action button (FAB) for rapid stock entry.

3. **[`inventory.html`](./inventory.html)**:
   - Live client-side search across item names, SKUs, and vendors.
   - Dual filter dropdowns for Categories and Stock Status.
   - 12-row inventory data matrix with color-coded status badges.
   - Interactive **Add New Item** modal dialog.
   - RFC-4180 CSV export functionality.

## 🎨 Visual Design System
- **Background**: Deep Charcoal (`#0A0D12`) with glassmorphic cards (`#10151E`)
- **Accents**: Warm Gold (`#D49B37`, `#F8DA96`) and Terracotta (`#992B15`)
- **Typography**: Playfair Display (headings) + Plus Jakarta Sans (body)
